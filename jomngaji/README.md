# JomNgaji Flutter App

## Development quick start

```bash
flutter pub get
flutter run
```

## Build artifacts

- APK (testing): `flutter build apk --release`
- AAB (Google Play): `flutter build appbundle --release`
- IPA (App Store, macOS): `flutter build ipa --release`
